# Graybox v0.3.1

**Published November 11, 2026.** [Download v0.3.1](https://github.com/ViniTamanhao/graybox-core/releases/tag/v0.3.1).
These notes describe changes since v0.3.0. The release tag resolves to
`f3dbb1fe08bc0959711f5f3d690ae5c7c695f746` on main.

## Highlights

- A redesigned README: immediate product explanation, a real authenticated
  response comparison, direct installation, and documentation grouped by task.
  The original SVG demonstration reproduces executed CLI output; it introduces
  no runtime dependency or generated terminal claims.
- One canonical Agent Skills package with documented installation conventions
  for Codex, Claude Code, Cursor and Copilot. The executable and instruction
  package are installed separately. This updates the skill shipped with v0.3.0;
  it does not add CLI functionality.
- Clearer release status, baseline provenance, safe replay guidance and evidence
  interpretation, including the distinction between a difference and a regression.

## Changes since v0.3.0

[PR #29](https://github.com/ViniTamanhao/graybox-core/pull/29) clarified published
installation, behavioral scope and the authenticated walkthrough.
[PR #30](https://github.com/ViniTamanhao/graybox-core/pull/30) added portable
installation guidance, structural package checks in four project directories,
client evidence-capture limits and explicit guidance against ambiguous-write retries.
[PR #31](https://github.com/ViniTamanhao/graybox-core/pull/31) redesigned the README,
added a verified output illustration and a lightweight documentation checker in
Linux CI, and raised the Go minimum to the patched toolchain.

Five fresh bounded Codex sessions in the portability work included an offline
ambiguous-write assessment, two environment-blocked development attempts, and
configured reruns for documentation and a seeded regression. The regression
rerun observed a pre-fix difference, correction and restored equivalence.
These are additional observations, not a new cross-client correctness claim.
See the [portability report](../agent-skill-portability.md) for setup, results and limits.

The minimum Go version is raised from 1.26.10 to **1.26.11**, addressing
[GO-2026-6859](https://vuln.go.dev/ID/GO-2026-6859.json) in the standard library.
CI and release builds already read go.mod and therefore select the patched
toolchain. Published v0.3.0 artifacts are not rebuilt by this change.

No new commands, replay capabilities, recording schema changes or module dependency
updates were introduced in v0.3.1.
Recording, inspection, sequential replay, semantic JSON/exact-body comparison,
redaction, runtime credentials, JSON output and exit codes are existing features.

## Agent compatibility

- **Codex:** bounded real-client validation, including fresh portability trials
  with Codex CLI 0.167.0. Historical campaigns remain separate evidence.
- **Claude Code, Cursor and Copilot:** documented installation compatibility and
  structural checks only. Live trials were blocked by unavailable clients;
  no completed live validation is recorded.

Installation does not guarantee selection, successful execution or improved
coding correctness. Native Windows skill installation and personal-scope runtime
discovery remain untested. See [installation and client paths](../agent-skill.md).

## Installation

Install with a patched Go toolchain (minimum Go 1.26.11):

```bash
go install github.com/ViniTamanhao/graybox-core/cmd/graybox@v0.3.1
graybox version --json
```

Expected output: `{"version":"v0.3.1"}`. Or download a native archive and
SHA256SUMS from the published release, then verify the checksum before extracting.
See the [installation guide](../installation.md) for platform-specific steps.
Install `skills/graybox` separately from the matching **v0.3.1 source tag** using
the [skill guide](../agent-skill.md). CLI archives do not include the skill.

## Compatibility and limitations

CLI behavior, JSON structures, documented exit codes, strict configuration,
mandatory redaction and SQLite schema-1 recordings remain unchanged. Source builds
require Go 1.26.11 or newer; prebuilt binaries need no Go installation.

A nonempty equivalent comparison covers selected recorded behavior under its
policy, not full correctness. Empty exit 0 provides no coverage; failed comparisons
remain inconclusive. Replay and diff execute real requests and can repeat writes.
Use authorized disposable targets and preserve trusted pre-change baselines.
No state reset, rollback, token refresh or generated-ID correlation is added.

Redaction is not universal secret detection. Recordings and reports remain
potentially sensitive. Keep them private and outside Git. See
[Security](../SECURITY.md) and the [verification contract](../agent-verification-contract.md).

## Verification evidence

Preparation detected `GO-2026-6859` with Go 1.27.3 locally and Go 1.26.10 in CI.
The minimum was then raised to Go 1.26.11; users building with the 1.27 line need
Go 1.27.4 or newer. The initial failures and patched-toolchain checks remain in
the [historical readiness record](v0.3.1-readiness.md).

The [release workflow](https://github.com/ViniTamanhao/graybox-core/actions/runs/43028509835)
completed its build, six-archive verification, macOS/Windows smoke tests and
publication jobs successfully. Post-publication checks verified the released
module and Linux AMD64 binary report v0.3.1, the published archive checksums,
and the matching five-file skill package in external projects. The downloaded
Linux AMD64 binary passed authenticated capture/change/restore and its binary
vulnerability scan reported no known vulnerabilities. These bounded checks do
not establish universal security or cross-client runtime compatibility.

See the dated post-publication section in the readiness record for commands,
results and limits. Other architectures were not executed locally; historical
agent trials were not rerun, and no new client inference campaign was performed.
