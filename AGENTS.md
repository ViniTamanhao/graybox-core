# Graybox repository instructions

Before modifying this repository, read [agents/README.md](agents/README.md) and
its activity-specific guides. They apply to human and AI contributions.

Preserve the local-first CLI, schema-1 recordings, documented exit codes and
mandatory redaction. Reproduce bugs with a failing behavior test before fixing
them. Update affected documentation as behavior changes, commit progressively,
and report only verification actually performed. Never commit recordings,
credentials, generated binaries, or unrelated changes. Do not publish releases,
merge, force-push, or perform destructive actions without task authorization.
